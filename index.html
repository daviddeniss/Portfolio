Aberto a vagas júnior

Sou estudante de Ciência da Computação e gosto de transformar problemas reais em software bem construído. Comecei pelo desenvolvimento web e, com o tempo, percebi que o que mais me motiva é o caminho completo: entender o problema, modelar os dados, escrever código testável e entregar algo que as pessoas consigam usar.

Na Iniciação Científica, isso virou o Emergy Analysis, uma ferramenta que calcula indicadores de sustentabilidade a partir de inventários de fluxos. Foi ali que juntei as duas áreas que quero seguir: a análise de dados, com Python e pandas, e a engenharia de software, com arquitetura em pacotes, testes automatizados e integração contínua.

Nos outros projetos explorei o resto da stack: uma API REST em Java com Spring Boot no EcoGrid e um dashboard em tempo real com Vue e TypeScript no Crypto Dashboard.

Hoje busco uma oportunidade como Engenheiro de Software Júnior ou Cientista de Dados Júnior, em um time onde eu possa aprender rápido e contribuir com código limpo, testado e orientado a dados.

Emergy Analysis

Projeto de Iniciação Científica para avaliação emergética de sistemas a partir de inventários de fluxos.

  • Monorepo com 3 pacotes (uv workspace): biblioteca, CLI e aplicação web
  • emergy-core: núcleo científico reutilizável com pandas, Pydantic e SQLAlchemy
  • CLI emergy com Typer + Rich e app interativo em Streamlit + Plotly
  • CLI e web usam o mesmo núcleo, então a mesma entrada sempre gera o mesmo resultado
  • Lê inventários CSV/XLSX e converte UEVs entre baselines (GEB2016, GEB2000…)
  • Testes com pytest e Hypothesis, CI, pre-commit e Docker

Crypto Dashboard

Acompanhamento do mercado de criptomoedas em tempo real, usando a API do CoinGecko e o WebSocket da Binance.

  • Top 100 moedas com busca, ordenação e filtro de favoritos
  • Preços ao vivo via WebSocket, assinando só as moedas visíveis, favoritas ou com alerta
  • Gráficos de 24h a 1 ano com Chart.js
  • Alertas de preço com notificação do sistema
  • Tema claro/escuro, mobile first e acessibilidade (contraste AA)
  • Reconexão com backoff exponencial e cache com TTL
  • Testes com Vitest + MSW e CI no GitHub Actions

EcoGrid Management

Trabalho acadêmico (APS, UNIP): gestão de eficiência energética e pegada de carbono.

  • Arquitetura cliente-servidor: API REST em Spring Boot + cliente desktop em JavaFX
  • Camadas Controller → Service → Repository com Spring Data JPA
  • H2 em desenvolvimento e PostgreSQL em produção, só trocando a configuração
  • Chamadas assíncronas com HttpClient + CompletableFuture, sem travar a interface
  • Auditoria ISO 14001, recomendações por fonte e simulação de créditos de carbono
  • 47 testes com JUnit, Mockito e MockMvc
